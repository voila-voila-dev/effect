```tsx

	<NativeSelectOptGroup label="Creative">
		<NativeSelectOption value="design">Design</NativeSelectOption>
	</NativeSelectOptGroup>
</NativeSelect>
```

No portal, no JavaScript for the popup: the OS draws the list. That makes it
the right choice on mobile and inside a form that has to work before hydration.
