```tsx
<Accordion defaultValue={["publishing"]}>
	<AccordionItem value="publishing">
		<AccordionTrigger>How do I publish a mission?</AccordionTrigger>
		<AccordionContent>
			<p>From your club dashboard, create a mission with…</p>
		</AccordionContent>
	</AccordionItem>
</Accordion>
```

`value` is an array even for a single open panel. Pass `multiple` to let several
stay open at once.
