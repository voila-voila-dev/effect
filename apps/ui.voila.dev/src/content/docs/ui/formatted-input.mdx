```tsx
<FormattedInput mask={siretMask} placeholder="123 456 789 00012" />
```

`siretMask`, `rppsMask` and `frenchPhoneMask` ship with the component. The
value you get back is unformatted, so what you store is digits and the grouping
is only ever presentation.
