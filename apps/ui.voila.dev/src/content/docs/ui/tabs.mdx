```tsx
<Tabs defaultValue="missions">
	<TabsList>
		<TabsTrigger value="missions">Missions</TabsTrigger>
		<TabsTrigger value="providers">Providers</TabsTrigger>
	</TabsList>
	<TabsContent value="missions">…</TabsContent>
	<TabsContent value="providers">…</TabsContent>
</Tabs>
```

`variant="line"` on the list swaps the filled rail for an underline, which sits
better directly under a page header.
