```ts
{
	id: "article",
	type: "article",
	title: "Bien choisir son kinésithérapeute",
	description: "Les trois critères qui comptent vraiment.",
	image: { src: "https://cdn.acme.dev/kine.png", alt: "Séance de kiné" },
	author: "Emma Martin",
	publishDate: "2026-07-20",
	href: "https://acme.dev/blog/choisir-son-kine",
}
```

The field names follow the blog content model, so building a digest from
published posts is a straight mapping. Empty strings stand for absent
optionals, and `publishDate` is formatted for the recipient at render.
