```ts
{
	id: "offer",
	type: "offer",
	eyebrow: "Le plus choisi",
	name: "Essentiel",
	description: "Le socle pour recruter en continu.",
	image: { src: "", alt: "" },
	price: { amountInMinorUnits: 2900, currency: "EUR" },
	period: "par mois",
	features: ["Missions illimitées", "Support 7j/7"],
	buttonLabel: "Choisir cette offre",
	buttonHref: "https://acme.dev/offres",
	highlighted: true,
}
```

`highlighted` draws the card in the brand colour, for the recommended plan of a
row. Leave `period` empty for a one-off price.
