```tsx
<IconPicker value={iconName} onValueChange={setIconName} />
```

The value is a Phosphor export name like `"FirstAidKitIcon"`, which is what
[Icon](/ui-icon/icon) renders. The grid caps at 120 swatches — the full set is
around 1,500 and is not virtualised — so the rest is reached by searching.
