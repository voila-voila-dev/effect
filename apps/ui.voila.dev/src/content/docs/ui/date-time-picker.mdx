```tsx
<DateTimePicker.Root value={value} onValueChange={setValue} placeholder="Project start" />
```

The namespace also carries `DateTimePicker.Range` for a start and an end,
`DateTimePicker.ShiftRange` for a shift that can cross midnight, and
`DateTimePicker.Native` / `DateTimePicker.Responsive` for the native-picker
variants.
