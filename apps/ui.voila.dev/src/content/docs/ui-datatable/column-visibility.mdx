```tsx
<DataTable
	columns={columns}
	data={projects}
	toolbar={(table) => (
		<DataTableToolbar>
			<DataTableActions>
				<DataTableViewOptions table={table} />
				<DataTableExport table={table} filename="projects.csv" />
			</DataTableActions>
		</DataTableToolbar>
	)}
/>;
```

`toolbar` takes a render prop when a control needs the table instance — the
column menu and the exporter both do.
