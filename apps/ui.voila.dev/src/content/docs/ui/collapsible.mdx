```tsx

	<Collapsible.Trigger render={<Button variant="ghost" size="icon-sm" />}>
		<CaretDownIcon />
	</Collapsible.Trigger>
	<Collapsible.Content>…</Collapsible.Content>
</Collapsible.Root>
```

One section with your own trigger, where [Accordion](/ui/accordion) is a set
with a house style. Rotate the caret off the trigger's `aria-expanded` rather
than tracking the open state yourself.
