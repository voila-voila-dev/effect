```tsx
<Drawer direction="right">
	<DrawerTrigger asChild>
		<Button variant="outline">View mission</Button>
	</DrawerTrigger>
	<DrawerContent>
		<DrawerHeader>
			<DrawerTitle>Match coverage — Saturday</DrawerTitle>
			<DrawerDescription>Stade Marcel Michelin, 14:00.</DrawerDescription>
		</DrawerHeader>
		<DrawerFooter>
			<Button>Apply to this mission</Button>
		</DrawerFooter>
	</DrawerContent>
</Drawer>
```

Built on [Vaul](https://vaul.emilkowal.ski/), which is why this one uses
`asChild` where the rest of the kit uses `render`.
