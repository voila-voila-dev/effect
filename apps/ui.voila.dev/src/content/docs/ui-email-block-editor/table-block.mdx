```ts
{
	id: "table",
	type: "table",
	headerRow: true,
	columns: [
		{ label: "Service", align: "left" },
		{ label: "Rate", align: "right" },
	],
	rows: [["UI design", "€60.00"]],
}
```

`rows` is row-major plain text. A row shorter than the column count renders
blank trailing cells rather than failing.
