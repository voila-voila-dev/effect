Every colour, radius and font in the system, as CSS custom properties in the
OKLch colour space. It is a stylesheet and nothing else — no JavaScript, no
build step, no config file.

You rarely install it directly: `@voila.dev/ui` depends on it and its
`globals.css` imports it for you. Install it on its own only when you want the
palette without the components.

## Install

```sh
bun add @voila.dev/ui-tokens
```

```css title="globals.css"
@import "tailwindcss";
@import "@voila.dev/ui-tokens/design-tokens.css";
```

To rebrand, redefine the properties you care about *after* the import. The
components follow, because they only ever reference the semantic names.

See [Theming and tokens](/start/theming/) for the full map.

Peers: `react@19`, `react-dom@19`, `tailwindcss@4`.
