```tsx
<StickyActionBar>
	<Button variant="outline">Contacter</Button>
	<Button>Postuler</Button>
</StickyActionBar>
```

It hides from the `md` breakpoint up, on the assumption that the same actions
are already visible in the desktop layout. Pass `hideOnDesktop={false}` when
they are not — which is what the preview above does.
