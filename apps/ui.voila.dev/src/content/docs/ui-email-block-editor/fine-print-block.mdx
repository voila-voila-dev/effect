```ts
{
	id: "fine-print",
	type: "finePrint",
	spans: [
		{ text: "LAUNCH10: 10% off the order total, valid until August 31. See the " },
		{ text: "terms and conditions", href: "https://acme.dev/terms" },
		{ text: "." },
	],
}
```

Small, muted and centred, so it reads as a footnote rather than as body copy.
It shares the [paragraph](/ui-email-block-editor/paragraph-block)'s span model,
so the conditions can link to the terms. Typically the last block of the email,
after the signature.
