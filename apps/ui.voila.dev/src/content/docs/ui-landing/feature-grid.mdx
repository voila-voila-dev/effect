```tsx
<FeatureGrid.Root tone="destructive" columns="3">
	<FeatureGrid.Card>
		<FeatureGrid.CardIcon><CurrencyDollarIcon /></FeatureGrid.CardIcon>
		<FeatureGrid.CardTitle>Unpredictable rates</FeatureGrid.CardTitle>
		<FeatureGrid.CardDescription>Budgets…</FeatureGrid.CardDescription>
	</FeatureGrid.Card>
</FeatureGrid.Root>
```

`tone` on the root tints every card's icon, which is how a pains section reads
as red and a benefits section as green without setting a colour per card.
