```tsx
<Eyebrow.Root tone="brand">
	<Eyebrow.Dot pulse />
	<Eyebrow.Label>Nouvelle plateforme</Eyebrow.Label>
</Eyebrow.Root>
```

`Dot` and `Icon` are alternatives, not a pair. Use the dot when the label is a
status, the icon when it names an audience.
