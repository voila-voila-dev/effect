```tsx
<ProseArticle>
	<div dangerouslySetInnerHTML={{ __html: post.html }} />
</ProseArticle>
```

This is the one place in the package that styles bare tags, because the content
comes from a CMS and cannot carry classes.

It is set for reading: 17 px on a phone and 18 px from `md`, at a 1.65 line
height, in a 40rem measure of about 68 characters a line. Body text is near-black
rather than grey — long reading in grey tires the eye — and bold runs carry a
faint brand highlight. Content from the content editor gets heading anchors,
scrolling tables and figures from [Article readers](/ui-landing/article-readers).
