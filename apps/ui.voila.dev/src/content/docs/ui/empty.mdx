```tsx
<Empty bordered>
	<EmptyHeader>
		<EmptyMedia variant="icon"><CalendarPlusIcon /></EmptyMedia>
		<EmptyTitle>No projects yet</EmptyTitle>
		<EmptyDescription>Create your first project to…</EmptyDescription>
	</EmptyHeader>
	<EmptyContent>
		<Button>Create a project</Button>
	</EmptyContent>
</Empty>
```

`EmptyMedia` takes `variant="icon"` for a tinted icon tile, or plain children
for anything else — an avatar, an illustration.
