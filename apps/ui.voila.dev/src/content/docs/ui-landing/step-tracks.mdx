```tsx
				</StepTracks.Body>
			</StepTracks.Step>
		</StepTracks.Steps>
	</StepTracks.Track>
	<StepTracks.Track tone="provider">…</StepTracks.Track>
</StepTracks.Root>
```

`number` on the step icon is explicit rather than derived, so a track can start
at something other than one.
