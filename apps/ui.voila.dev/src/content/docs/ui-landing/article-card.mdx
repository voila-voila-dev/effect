```tsx
<ArticleCard.Root href="/blog/my-article">
	<ArticleCard.Frame>
		<ArticleCard.Image src={cover} alt="Cover" />
		<ArticleCard.Content>
			<ArticleCard.Tags>
				<ArticleTags.Tag>Hiring</ArticleTags.Tag>
			</ArticleCard.Tags>
			<ArticleCard.Title>Why brief your freelancer…</ArticleCard.Title>
			<ArticleCard.Description>Every kickoff…</ArticleCard.Description>
			<ArticleCard.Meta>
				<ArticleCard.MetaItems>
					<ArticleCard.MetaItem><CalendarBlankIcon />July 12, 2026</ArticleCard.MetaItem>
				</ArticleCard.MetaItems>
				<ArticleCard.Arrow />
			</ArticleCard.Meta>
		</ArticleCard.Content>
	</ArticleCard.Frame>
</ArticleCard.Root>
```

`Root` is the link, so nothing inside it should be one. Posts with no cover use
`ArticleCard.ImageFallback`, which keeps the card the same height as its
neighbours in a grid.
