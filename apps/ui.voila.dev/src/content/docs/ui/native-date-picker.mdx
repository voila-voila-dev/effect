```tsx
<NativeDatePicker.Date defaultValue="2026-06-20" min="2026-06-01" max="2026-06-30" />
<NativeDatePicker.Time defaultValue="14:30" />
<NativeDatePicker.DateTime defaultValue="2026-06-20T14:30" />
```

Real `<input type="date">` elements, so the OS draws the picker and the value
is an ISO string. On a phone that is a better picker than anything drawn in the
page.
