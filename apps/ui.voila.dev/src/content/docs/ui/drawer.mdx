```tsx
<Drawer.Root direction="right">
	<Drawer.Trigger asChild>
		<Button variant="outline">View project</Button>
	</Drawer.Trigger>
	<Drawer.Content>
		<Drawer.Header>
			<Drawer.Title>Launch review — Saturday</Drawer.Title>
			<Drawer.Description>Kickoff call · Zoom, 14:00.</Drawer.Description>
		</Drawer.Header>
		<Drawer.Footer>
			<Button>Apply to this project</Button>
		</Drawer.Footer>
	</Drawer.Content>
</Drawer.Root>
```

Built on [Vaul](https://vaul.emilkowal.ski/), which is why this one uses
`asChild` where the rest of the kit uses `render`.
