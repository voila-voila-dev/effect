```tsx
<Chart.Radar dots inset={92} />
```

`inset` reserves the ring's outer margin for the axis labels, which are drawn
outside it.

A radar needs the polar pair rather than
[Chart.XAxis](/ui-chart/chart-x-axis) and [Chart.YAxis](/ui-chart/chart-y-axis):
the rings are the value scale and the spokes are the categories.
