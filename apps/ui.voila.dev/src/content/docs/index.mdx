## Install

```sh
bun add @voila.dev/ui @voila.dev/ui-tokens
```

```css
/* your globals.css */
@import "tailwindcss";
@import "@voila.dev/ui/styles/globals.css";
```

That is the whole setup. Peers are `react@19`, `react-dom@19` and `tailwindcss@4`.

## The packages

| Package | What it is |
| --- | --- |
| [`@voila.dev/ui`](https://www.npmjs.com/package/@voila.dev/ui) | The core: ~80 components, from `Button` to `Sidebar`. |
| [`@voila.dev/ui-tokens`](https://www.npmjs.com/package/@voila.dev/ui-tokens) | The design tokens, as plain CSS custom properties. |
| [`@voila.dev/ui-chart`](https://www.npmjs.com/package/@voila.dev/ui-chart) | Composable SVG charts, no charting library underneath. |
| [`@voila.dev/ui-spreadsheet`](https://www.npmjs.com/package/@voila.dev/ui-spreadsheet) | `DataTable` and a virtualized, keyboard-driven `EditableTable`. |
| [`@voila.dev/ui-map`](https://www.npmjs.com/package/@voila.dev/ui-map) | A lazy-loaded MapLibre GL map view. |
| [`@voila.dev/ui-filter`](https://www.npmjs.com/package/@voila.dev/ui-filter) | A filter toolbar and pager for list pages. |
| [`@voila.dev/ui-landing`](https://www.npmjs.com/package/@voila.dev/ui-landing) | Marketing sections: heroes, feature grids, testimonials, footers. |
| [`@voila.dev/ui-email-block-editor`](https://www.npmjs.com/package/@voila.dev/ui-email-block-editor) | A drag-and-drop block editor for marketing emails. |

All of them publish in lockstep at one version, so cross-package versions always line up.

## Why source, not a bundle

A compiled component library is a wall. You can style around it, but you cannot
see what it does, you cannot step into it, and the day you need a variant it
does not have, you are stuck.

Shipping source removes the wall. The trade is that your bundler compiles a few
thousand more lines. In exchange, `Cmd+click` on any component takes you to the
code that renders it.
