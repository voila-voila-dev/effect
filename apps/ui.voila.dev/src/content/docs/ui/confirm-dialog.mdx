```tsx
<ConfirmDialog
	trigger={<Button variant="outline">Archive mission</Button>}
	title="Archive this mission?"
	description="The mission will be hidden from the active list."
	confirmLabel="Archive"
	onConfirm={() => archiveMission(id)}
/>
```

If `onConfirm` returns a promise the confirm button shows a spinner until it
settles, and the dialog stays open if it rejects — so a failed request leaves
the user where they can retry.
