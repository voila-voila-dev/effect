```tsx
<LandingHero.Root>
	<LandingHero.Content>
		<LandingHero.Title>
			Trouvez un{" "}
			<LandingHero.Highlight tone="provider">pro de santé</LandingHero.Highlight>
		</LandingHero.Title>
		<LandingHero.Lead>La plateforme qui met en relation…</LandingHero.Lead>
		<LandingHero.Actions>
			<Button size="lg">Je suis un club</Button>
		</LandingHero.Actions>
	</LandingHero.Content>
	<LandingHero.Media>
		<HeroIllustration />
	</LandingHero.Media>
</LandingHero.Root>
```

Drop `LandingHero.Media` and pass `layout="centered"` for a hero with no
illustration.
