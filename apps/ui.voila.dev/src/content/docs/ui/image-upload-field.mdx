```tsx
<ImageUploadField
	value={avatarUrl}
	onFileCropped={upload}
	onRemove={clear}
	shape="circle"
/>
```

`shape="rectangle"` with an `aspectRatio` covers a banner. `onFileCropped`
receives the cropped file, so the upload stays yours.
