```ts
{
	id: "article",
	type: "article",
	title: "How to choose the right freelancer",
	description: "The three criteria that actually matter.",
	image: { src: "https://cdn.acme.dev/brief.png", alt: "Freelancer at work" },
	author: "Emma Martin",
	publishDate: "2026-07-20",
	href: "https://acme.dev/blog/choosing-a-freelancer",
}
```

The field names follow the blog content model, so building a digest from
published posts is a straight mapping. Empty strings stand for absent
optionals, and `publishDate` is formatted for the recipient at render.
