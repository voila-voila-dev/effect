```tsx
<DataTable.Root
	columns={columns}
	data={projects}
	toolbar={(table) => (
		<DataTable.Toolbar>
			<DataTable.Actions>
				<DataTable.ViewOptions table={table} />
				<DataTable.Export table={table} filename="projects.csv" />
			</DataTable.Actions>
		</DataTable.Toolbar>
	)}
/>;
```

`toolbar` takes a render prop when a control needs the table instance — the
column menu and the exporter both do.

## API

<PropTable of="DataTable.ViewOptions" />

`table` is the live instance, which is why `toolbar` has to be a render prop
here: the menu builds itself from the column list at render time, so a column
added later appears without touching this.
