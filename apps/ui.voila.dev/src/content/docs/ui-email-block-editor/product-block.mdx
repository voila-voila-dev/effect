```ts
{
	id: "product",
	type: "product",
	name: "Bande de contention Essity",
	description: "Boîte de 10, largeur 10 cm.",
	image: { src: "https://cdn.acme.dev/bande.png", alt: "Bande" },
	price: { amountInMinorUnits: 5990, currency: "EUR" },
	compareAtPrice: { amountInMinorUnits: 7990, currency: "EUR" },
	href: "https://shop.acme.dev/bande-contention",
	buttonLabel: "Commander",
}
```

Prices are integer minor units plus a currency, never a pre-formatted string.
One campaign can go out in several locales, so the formatting happens at render.
Set `compareAtPrice` to `null` when the product is not discounted.
