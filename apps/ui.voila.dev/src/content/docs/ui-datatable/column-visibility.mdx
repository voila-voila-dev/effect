```tsx
<DataTable.Root
	columns={columns}
	data={projects}
	toolbar={(table) => (
		<DataTable.Toolbar>
			<DataTable.Actions>
				<DataTable.ViewOptions table={table} />
				<DataTable.Export table={table} filename="projects.csv" />
			</DataTable.Actions>
		</DataTable.Toolbar>
	)}
/>;
```

`toolbar` takes a render prop when a control needs the table instance — the
column menu and the exporter both do.
