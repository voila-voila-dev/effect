```ts
{
	id: "table",
	type: "table",
	headerRow: true,
	columns: [
		{ label: "Prestation", align: "left" },
		{ label: "Tarif", align: "right" },
	],
	rows: [["Kinésithérapie", "60,00 €"]],
}
```

`rows` is row-major plain text. A row shorter than the column count renders
blank trailing cells rather than failing.
