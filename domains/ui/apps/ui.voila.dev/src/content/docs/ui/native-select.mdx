```tsx
<NativeSelect.Root defaultValue="design">
	<NativeSelect.OptGroup label="Creative">
		<NativeSelect.Option value="design">Design</NativeSelect.Option>
	</NativeSelect.OptGroup>
</NativeSelect.Root>
```

No portal, no JavaScript for the popup: the OS draws the list. That makes it
the right choice on mobile and inside a form that has to work before hydration.
