```tsx
<Section.Root>
	<Section.Header>
		<Section.Heading>
			<Section.Title>Upcoming projects</Section.Title>
			<Section.Description>This week's projects.</Section.Description>
		</Section.Heading>
		<Section.Actions>
			<Button variant="ghost" size="sm">View all</Button>
		</Section.Actions>
	</Section.Header>
	<Card.Root>…</Card.Root>
</Section.Root>
```

`Section.Title` renders an `h2`. When sections nest, pass `render={<h3 />}` to
keep the heading outline honest.

This is the application-side section. Marketing pages have their own, wider one
in [ui-landing](/ui-landing/section/).
