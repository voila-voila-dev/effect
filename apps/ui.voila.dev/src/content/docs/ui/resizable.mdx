```tsx
<div className="h-48">
	<ResizablePanelGroup>
		<ResizablePanel defaultSize={50}>…</ResizablePanel>
		<ResizableHandle withHandle />
		<ResizablePanel defaultSize={50}>…</ResizablePanel>
	</ResizablePanelGroup>
</div>
```

The group fills its parent, so the size goes on a wrapper and never on
`ResizablePanelGroup` itself. A panel with `collapsible` and `collapsedSize={0}`
snaps shut when dragged to the edge.
