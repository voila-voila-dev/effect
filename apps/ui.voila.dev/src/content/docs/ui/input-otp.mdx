```tsx
<InputOTP maxLength={6} pattern={REGEXP_ONLY_DIGITS}>
	<InputOTPGroup>
		<InputOTPSlot index={0} />
		<InputOTPSlot index={1} />
		<InputOTPSlot index={2} />
	</InputOTPGroup>
	<InputOTPSeparator />
	<InputOTPGroup>…</InputOTPGroup>
</InputOTP>
```

Built on [input-otp](https://input-otp.rodz.dev/), so it is one real input
behind the boxes — paste, autofill from an SMS, and select-all all work.
