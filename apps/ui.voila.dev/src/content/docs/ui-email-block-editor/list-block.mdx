```ts
{
	id: "list",
	type: "list",
	marker: "badge",
	items: [
		{ spans: [{ text: "Post your project", bold: true }] },
		{ spans: [{ text: "Pay once the project is delivered." }] },
	],
}
```

Items use the same span model as the paragraph, so bold, italic and links work
inside them. Enter starts the next item and puts the caret in it; Shift+Enter
breaks the line inside the current one.
