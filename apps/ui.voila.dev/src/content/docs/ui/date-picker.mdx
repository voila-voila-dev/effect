```tsx
<DatePicker.Root
	value={date}
	onValueChange={setDate}
	placeholder="Project date"
	locale="en-GB"
/>
```

`calendarProps` passes through to the [Calendar](/ui/calendar/) underneath —
`defaultMonth`, `disabled`, and so on. `DatePicker.Range` is the two-date
version, and `DatePicker.Trigger` is the field on its own.
