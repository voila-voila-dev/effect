```tsx
<Sidebar.Provider>
	<Sidebar.Root collapsible="icon">
		<Sidebar.Header>…</Sidebar.Header>
		<Sidebar.Content>
			<Sidebar.Group>
				<Sidebar.GroupLabel>Platform</Sidebar.GroupLabel>
				<Sidebar.GroupContent>
					<Sidebar.Menu>
						<Sidebar.MenuItem>
							<Sidebar.MenuButton isActive tooltip="Dashboard">
								<HouseIcon />
								<span>Dashboard</span>
							</Sidebar.MenuButton>
						</Sidebar.MenuItem>
					</Sidebar.Menu>
				</Sidebar.GroupContent>
			</Sidebar.Group>
		</Sidebar.Content>
	</Sidebar.Root>
	<Sidebar.Inset>
		<header><Sidebar.Trigger /></header>
	</Sidebar.Inset>
</Sidebar.Provider>
```

`collapsible` takes `offcanvas` (slides away), `icon` (collapses to a rail of
icons) or `none`. With `icon`, the `tooltip` on each menu button is what labels
it once the text is hidden, so pass it always.

The provider stores the open state in a cookie, so the sidebar comes back the
way the user left it.
