```tsx
<List aria-label="Open projects">
	<ListItem variant="outline">
		<ItemMedia variant="icon"><CalendarCheckIcon /></ItemMedia>
		<ItemContent>
			<ItemTitle>Landing page redesign</ItemTitle>
		</ItemContent>
	</ListItem>
</List>
```

`List` renders a `<ul>` and `ListItem` an `<li>`, taking the same children as
[Item](/ui/item/). Give the list an `aria-label` — a screen reader announces
the count, and "list of 12" is only useful if it says a list of what.
