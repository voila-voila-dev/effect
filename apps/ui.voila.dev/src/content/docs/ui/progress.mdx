```tsx
<Progress value={35}>
	<ProgressLabel>Profile completion</ProgressLabel>
	<ProgressValue />
</Progress>
```

`value={null}` is the indeterminate state — the bar loops instead of filling.
`ProgressValue` takes a formatter child when a percentage is not what you want
to show.
