```tsx
<Section>
	<SectionHeader>
		<SectionHeading>
			<SectionTitle>Upcoming projects</SectionTitle>
			<SectionDescription>This week's projects.</SectionDescription>
		</SectionHeading>
		<SectionActions>
			<Button variant="ghost" size="sm">View all</Button>
		</SectionActions>
	</SectionHeader>
	<Card>…</Card>
</Section>
```

`SectionTitle` renders an `h2`. When sections nest, pass `render={<h3 />}` to
keep the heading outline honest.

This is the application-side section. Marketing pages have their own, wider one
in [ui-landing](/ui-landing/section/).
