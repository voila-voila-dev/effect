```tsx
<HoverCard.Root>
	<HoverCard.Trigger render={<a href={profileUrl} />}>@nathan.guyot</HoverCard.Trigger>
	<HoverCard.Content>
		<ProviderPreview />
	</HoverCard.Content>
</HoverCard.Root>
```

Hover only opens it on a pointer, so nothing here can be the only way to reach
the information.
