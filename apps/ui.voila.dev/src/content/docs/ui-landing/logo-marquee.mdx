```tsx
<LogoMarquee.Root>
	<LogoMarquee.Title>Ils nous font confiance</LogoMarquee.Title>
	<LogoMarquee.Viewport>
		<LogoMarquee.Track duration={30}>
			<LogoMarquee.Item src={logo} alt="Northwind" />
		</LogoMarquee.Track>
	</LogoMarquee.Viewport>
</LogoMarquee.Root>
```

`Track` duplicates its children to make the loop seamless. For a handful of
logos that fit on one line, swap it for `StaticTrack` and drop the viewport.
