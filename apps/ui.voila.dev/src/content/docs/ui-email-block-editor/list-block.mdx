```ts
{
	id: "list",
	type: "list",
	marker: "badge",
	items: [
		{ title: "Publiez votre mission", spans: [{ text: "En deux minutes." }] },
		{ spans: [{ text: "Payez une fois la mission terminée." }] },
	],
}
```

Item bodies use the same span model as the paragraph, so bold, italic and links
work inside them.
