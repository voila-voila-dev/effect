```tsx
<Tooltip.Root>
	<Tooltip.Trigger render={<Button size="icon" aria-label="Save" />}>
		<FloppyDiskIcon />
	</Tooltip.Trigger>
	<Tooltip.Content>Save report</Tooltip.Content>
</Tooltip.Root>
```

A tooltip is a label, not a place to put content — it cannot hold anything
focusable, and it never carries information that is not available elsewhere. An
icon-only button still needs its own `aria-label`.
