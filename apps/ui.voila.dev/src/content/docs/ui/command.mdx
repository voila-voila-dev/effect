```tsx
<Command.Root>
	<Command.Input placeholder="Search projects, freelancers…" />
	<Command.List>
		<Command.Empty>No results found.</Command.Empty>
		<Command.Group heading="Projects">
			<Command.Item>
				<CalendarIcon />
				Launch review — Saturday
			</Command.Item>
		</Command.Group>
	</Command.List>
</Command.Root>
```

Built on [cmdk](https://cmdk.paco.me/), so an item's `value` and `keywords`
drive the filtering — set them when the visible label is not what people will
type. `Command.Dialog` wraps the same list in a modal, and the
`useCommandPalette` hook wires up the ⌘K shortcut.
