```tsx
<Pagination.Root>
	<Pagination.Content>
		<Pagination.Item><Pagination.Previous href="?page=1" /></Pagination.Item>
		<Pagination.Item><Pagination.Link href="?page=2" isActive>2</Pagination.Link></Pagination.Item>
		<Pagination.Item><Pagination.Ellipsis /></Pagination.Item>
		<Pagination.Item><Pagination.Next href="?page=3" /></Pagination.Item>
	</Pagination.Content>
</Pagination.Root>
```

These are links, so the page number belongs in the URL. Omit `href` on
`Pagination.Previous` or `Pagination.Next` at the ends of the range and they
render disabled rather than navigating nowhere.

For a paginated table, [DataTable](/ui-datatable/pagination) has this wired up
already.

## Windowing the page numbers

`usePagination` from `@voila.dev/ui/hooks` turns a page and a page count into
the items to render: zero-based page indexes and `PAGINATION_ELLIPSIS` where
pages are elided, always the same length so the bar does not jump as the
current page moves. `getPaginationRange` is the same, outside React.

```tsx
const items = usePagination({ page, pageCount, siblingCount: 1, boundaryCount: 1 });

<Pagination.Content>
	{items.map((item, index) =>
		item === PAGINATION_ELLIPSIS ? (
			<Pagination.Item key={`gap-${index}`}><Pagination.Ellipsis /></Pagination.Item>
		) : (
			<Pagination.Item key={item}>
				<Pagination.Link isActive={item === page} onClick={() => setPage(item)}>
					{item + 1}
				</Pagination.Link>
			</Pagination.Item>
		),
	)}
</Pagination.Content>
```
