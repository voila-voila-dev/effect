```tsx
		<LandingHero.Actions>
			<Button size="lg">I'm hiring</Button>
		</LandingHero.Actions>
	</LandingHero.Content>
	<LandingHero.Media>
		<HeroIllustration />
	</LandingHero.Media>
</LandingHero.Root>
```

Drop `LandingHero.Media` and pass `layout="centered"` for a hero with no
illustration.
