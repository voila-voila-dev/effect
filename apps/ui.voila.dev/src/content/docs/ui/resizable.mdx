```tsx
<div className="h-48">
	<Resizable.PanelGroup>
		<Resizable.Panel defaultSize={50}>…</Resizable.Panel>
		<Resizable.Handle withHandle />
		<Resizable.Panel defaultSize={50}>…</Resizable.Panel>
	</Resizable.PanelGroup>
</div>
```

The group fills its parent, so the size goes on a wrapper and never on
`Resizable.PanelGroup` itself. A panel with `collapsible` and `collapsedSize={0}`
snaps shut when dragged to the edge.
