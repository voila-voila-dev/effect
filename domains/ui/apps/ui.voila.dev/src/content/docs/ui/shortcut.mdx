```tsx
<Shortcut>⌘K</Shortcut>
<Shortcut keys={["⌘", "K"]} />
```

The `keys` form renders each key as a [Kbd](/ui/kbd); the children form is
plain muted text. Menus have their own version of this —
`DropdownMenu.Shortcut` and its siblings — which is what you want inside one.
