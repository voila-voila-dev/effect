```tsx
<Banner.Root variant="warning">
	<WarningIcon />
	<Banner.Title>Votre compte Stripe est incomplet.</Banner.Title>
	<Banner.Close />
</Banner.Root>
```

An [Alert](/ui/alert/) talks about the content it sits next to; a banner talks
about the whole session, which is why it is full-bleed and has no description
slot.

<Preview layout="stack">
	<Example.BannerWithAction />
</Preview>

`Banner.Close` does not remove the banner by itself. Wire its `onClick` to
whatever holds the dismissed state, so it stays dismissed on the next page.
