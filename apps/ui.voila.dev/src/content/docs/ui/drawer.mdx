```tsx
<Drawer direction="right">
	<DrawerTrigger asChild>
		<Button variant="outline">View project</Button>
	</DrawerTrigger>
	<DrawerContent>
		<DrawerHeader>
			<DrawerTitle>Launch review — Saturday</DrawerTitle>
			<DrawerDescription>Kickoff call · Zoom, 14:00.</DrawerDescription>
		</DrawerHeader>
		<DrawerFooter>
			<Button>Apply to this project</Button>
		</DrawerFooter>
	</DrawerContent>
</Drawer>
```

Built on [Vaul](https://vaul.emilkowal.ski/), which is why this one uses
`asChild` where the rest of the kit uses `render`.
