```tsx
<DataTable
	columns={columns}
	data={missions}
	columnPinning={{ left: ["reference"], right: ["amount"] }}
/>;
```

Pinned columns stack, so several per side work. An edge rule marks where the
frozen part ends — without it the two run together mid-scroll.
