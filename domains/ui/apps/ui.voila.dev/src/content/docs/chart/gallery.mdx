Every preview is a `<Chart>` with one definition. Tab into any of them and use
the arrow keys.

## Bars

`barY` and `barX`. Series stack by colour; `group: true` puts them side by
side; `projected` hatches the bars that are pencilled in rather than recorded.

`tickY` puts a short stroke on each bar (a target per month), `tickX` one per
value along a category (a strip plot).

## Lines and areas

`lineY`, `lineX`, `areaY`, `areaX`. A gap in the data is a gap in the line;
areas stack by colour, and `from`/`to` draw a band between two values.

Each behind its own subpath, with the d3 layout it needs:

`@voila.dev/chart/sankey`, `@voila.dev/chart/force` (`forceGraph`),

`@voila.dev/chart/contour` (`density2d`), `@voila.dev/chart/voronoi`.

```tsx
import { geoDot, geoShape, projection } from "@voila.dev/chart/geo";

defineChart({
	projection: projection("france", { domain: regions }),
	marks: [
		geoShape(regions.features, { name: (r) => r.properties.nom, color: (r) => r.properties.missions }),
		geoDot(cities, { longitude: "lon", latitude: "lat", name: "city", r: "missions" }),
	],
});
```
