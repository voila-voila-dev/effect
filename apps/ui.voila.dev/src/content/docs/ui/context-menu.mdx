```tsx
<ContextMenu>
	<ContextMenuTrigger className="…">Right-click here</ContextMenuTrigger>
	<ContextMenuContent>
		<ContextMenuItem>Edit mission</ContextMenuItem>
		<ContextMenuSeparator />
		<ContextMenuItem variant="destructive">Cancel mission</ContextMenuItem>
	</ContextMenuContent>
</ContextMenu>
```

There is no right-click on a touchscreen, so anything here needs a second route
— usually the same items in a [DropdownMenu](/ui/dropdown-menu/).
