First release: `@voila.dev/docs` holds the framework-free half of a documentation site (navigation registry, reader contexts, typo-tolerant search, a link graph check, an OpenAPI reference model and the MDX pipeline for Vite), and `@voila.dev/ui-docs` its React layer (frame, sidebar, outline, search palette, guide chrome, MDX components and API reference pages) on Tailwind CSS 4 and Base UI.
