```ts
{
	id: "list",
	type: "list",
	marker: "badge",
	items: [
		{ title: "Post your project", spans: [{ text: "In two minutes." }] },
		{ spans: [{ text: "Pay once the project is delivered." }] },
	],
}
```

Item bodies use the same span model as the paragraph, so bold, italic and links
work inside them.
