```tsx
<StatsRow.Root>
	<StatsRow.Item>
		<StatsRow.Value>20K+</StatsRow.Value>
		<StatsRow.Label>Membres engagés</StatsRow.Label>
	</StatsRow.Item>
	<StatsRow.Divider />
	<StatsRow.Item>…</StatsRow.Item>
</StatsRow.Root>
```

The dividers are your own children rather than something the root injects, so a
two-column row and a four-column row both work without a count prop.
