```tsx
<FieldGroup>
	<Field>
		<FieldLabel htmlFor="organization-name">Club name</FieldLabel>
		<Input id="organization-name" />
		<FieldDescription>Shown to providers on every mission.</FieldDescription>
	</Field>
	<Field data-invalid>
		<FieldLabel htmlFor="contact-email">Contact email</FieldLabel>
		<Input id="contact-email" aria-invalid />
		<FieldError>Enter a complete email address.</FieldError>
	</Field>
</FieldGroup>
```

`FieldSet` and `FieldLegend` wrap a group of related fields in the right
semantics; `FieldSeparator` takes a label for an "Optional" divider.
