```tsx
<ProfileHeader
	name="Camille Dubois"
	headline="Senior product designer"
	theme="brand"
	avatar={{ src: user.avatarUrl, name: user.name }}
	badges={<Badge variant="brand">Identity verified</Badge>}
	actions={<Button size="sm">Contact</Button>}
/>
```

`theme` picks the accent — `brand` or `highlight` — which tints
the gradient used when there is no cover image.
