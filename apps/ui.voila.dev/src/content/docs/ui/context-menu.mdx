```tsx
<ContextMenu.Root>
	<ContextMenu.Trigger className="…">Right-click here</ContextMenu.Trigger>
	<ContextMenu.Content>
		<ContextMenu.Item>Edit project</ContextMenu.Item>
		<ContextMenu.Separator />
		<ContextMenu.Item variant="destructive">Cancel project</ContextMenu.Item>
	</ContextMenu.Content>
</ContextMenu.Root>
```

There is no right-click on a touchscreen, so anything here needs a second route
— usually the same items in a [DropdownMenu](/ui/dropdown-menu/).
