```tsx
const columns: ColumnDef<Mission>[] = [
	{ accessorKey: "reference", header: "Reference", size: 130 },
	{ accessorKey: "club", header: "Club" },
	{ accessorKey: "amount", header: "Amount", size: 110 },
];

<DataTable columns={columns} data={missions} />;
```

A column with a numeric `size` switches the table to fixed layout, and sized
cells truncate instead of stretching.
