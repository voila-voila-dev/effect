The divider is part of `createContentFeatures`. It is drawn in
`theme.color.border`, so the email appearance shows the rule the sent email
has in the host's palette.

</Preview>

## Typing

- `---` on an empty line, or **Divider** in the slash menu, adds one.
- It is a void element: the arrow keys select it and Backspace deletes it.

## The stored node

```json
{ "type": "hr", "children": [{ "text": "" }] }
```

The email block editor's `divider` block maps to it.
