```tsx
<Avatar.Root>
	<Avatar.Image src={user.avatarUrl} alt={user.name} />
	<Avatar.Fallback>CD</Avatar.Fallback>
</Avatar.Root>
```

The fallback shows while the image loads and stays if it fails, so always give
one. `Avatar.Group` overlaps a row of them and `Avatar.GroupCount` closes it with
an overflow count.

For a name and a role next to the picture, [UserAvatar](/ui/user-avatar/) does
that in one component.
