```tsx
<Menubar>
	<MenubarMenu>
		<MenubarTrigger>Projects</MenubarTrigger>
		<MenubarContent>
			<MenubarItem>New project <MenubarShortcut>⌘N</MenubarShortcut></MenubarItem>
			<MenubarSeparator />
			<MenubarItem variant="destructive">Cancel project</MenubarItem>
		</MenubarContent>
	</MenubarMenu>
</Menubar>
```

Once one menu is open, moving across the bar opens the others on hover.
