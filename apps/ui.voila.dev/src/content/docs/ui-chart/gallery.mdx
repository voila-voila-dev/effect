## Own it

Every mark above is drawn by the source in
`@voila.dev/ui/src/chart/components/` — one file per mark, plain SVG, plain
arithmetic. To add a mark of your own, read one of the small ones
(`chart-points.tsx` is a good start) and write a sibling; it is the same file
whether you keep the package or copy it into your repo.
