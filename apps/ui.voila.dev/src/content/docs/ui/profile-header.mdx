```tsx
<ProfileHeader
	name="Camille Dubois"
	headline="Kinésithérapeute du sport"
	theme="provider"
	avatar={{ src: user.avatarUrl, name: user.name }}
	badges={<Badge variant="provider">Identité vérifiée</Badge>}
	actions={<Button size="sm">Contacter</Button>}
/>
```

`theme` picks the product surface — `provider` or `organization` — which tints
the gradient used when there is no cover image.
