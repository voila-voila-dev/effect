```tsx
<Calendar mode="single" selected={date} onSelect={setDate} />
<Calendar mode="range" selected={range} onSelect={setRange} />
```

Built on [React DayPicker](https://daypicker.dev/), so its `mode`, `disabled`,
`locale` and the rest apply. Inside a popover trigger, use
[DatePicker](/ui/date-picker/) instead — this is the bare grid.
