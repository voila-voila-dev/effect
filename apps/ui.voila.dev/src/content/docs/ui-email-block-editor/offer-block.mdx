```ts
{
	id: "offer",
	type: "offer",
	eyebrow: "Most popular",
	name: "Essential",
	description: "The foundation for hiring on repeat.",
	image: { src: "", alt: "" },
	price: { amountInMinorUnits: 2900, currency: "EUR" },
	period: "per month",
	features: ["Unlimited projects", "7-day support"],
	buttonLabel: "Choose this plan",
	buttonHref: "https://acme.dev/pricing",
	highlighted: true,
}
```

`highlighted` draws the card in the brand colour, for the recommended plan of a
row. Leave `period` empty for a one-off price.
