```tsx
<ToggleGroup defaultValue={["week"]} variant="outline">
	<ToggleGroupItem value="day">Day</ToggleGroupItem>
	<ToggleGroupItem value="week">Week</ToggleGroupItem>
</ToggleGroup>
```

The value is an array either way; `multiple` is what lets more than one entry
into it. Icon-only items need an `aria-label`.

For the single-choice view switcher with a sliding thumb, use
[SegmentedControl](/ui/segmented-control/).
