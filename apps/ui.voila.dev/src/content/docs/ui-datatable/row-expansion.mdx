```tsx
<DataTable.Root
	columns={columns}
	data={projects}
	renderExpandedRow={(project) => <ProjectDetail project={project} />}
/>;
```

Supplying the prop is what makes rows expandable — each grows a caret in a
leading cell, and the panel spans the full width beneath it.
