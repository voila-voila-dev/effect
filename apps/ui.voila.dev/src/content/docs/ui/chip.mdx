```tsx
<Chip variant="secondary">
	Kinésithérapie du sport
	<ChipRemove aria-label="Retirer Kinésithérapie du sport" />
</Chip>
```

A chip is something the user put there and can take away; a
[Badge](/ui/badge/) is something the data says. Give `ChipRemove` an
`aria-label` naming what it removes — "Remove" alone is useless in a row of six.
