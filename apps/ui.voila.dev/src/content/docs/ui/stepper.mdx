```tsx
<Stepper value={2}>
	<StepperItem step={1}>
		<StepperIndicator />
		<StepperTitle>Profil</StepperTitle>
		<StepperSeparator />
	</StepperItem>
	<StepperItem step={2}>…</StepperItem>
</Stepper>
```

`value` is the step the user is on; each item knows whether it is done, current
or still ahead from its own `step`. Leave the separator off the last item.

`orientation="vertical"` stacks the steps, with `StepperDescription` under each
title.
