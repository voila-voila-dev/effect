```ts
{
	id: "paragraph",
	type: "paragraph",
	spans: [
		{ text: "Discover the " },
		{ text: "newest projects", bold: true },
		{ text: " or head to " },
		{ text: "your workspace", href: "https://app.acme.dev" },
	],
}
```

Rich text is a flat list of spans rather than a tree, which is what makes it
safe to render into an email: escape the text, wrap the marks, done.
