```tsx
<Sheet>
	<SheetTrigger render={<Button variant="outline" />}>Details</SheetTrigger>
	<SheetContent side="right" size="lg">
		<SheetHeader>
			<SheetTitle>Mission details</SheetTitle>
			<SheetDescription>Pitch-side cover for Saturday.</SheetDescription>
		</SheetHeader>
		<SheetFooter>
			<Button>Confirm booking</Button>
		</SheetFooter>
	</SheetContent>
</Sheet>
```

`side` takes `top`, `right`, `bottom` or `left`; `size` runs `sm` through `full`.
