```tsx
<DataTable
	columns={[
		dataTableSelectionColumn<Mission>({
			selectAllLabel: "Select all missions",
			selectRowLabel: (mission) => `Select ${mission.reference}`,
		}),
		...columns,
	]}
	data={missions}
	enableRowSelection
	getRowId={(mission) => mission.reference}
/>;
```

`getRowId` is what makes a selection survive pagination — without it rows are
keyed by index, so page 2 "inherits" page 1's ticks.
