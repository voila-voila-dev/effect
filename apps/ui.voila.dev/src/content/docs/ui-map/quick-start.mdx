`MapView` owns the canvas, the MapLibre lifecycle and the navigation control,
and hands you the instance — markers and layers are yours. `RadiusMap` builds on
it for the common "a place and a radius" case.

MapLibre is about 270 kB gzipped, so the rendering body sits behind
`React.lazy` and only downloads once a map actually mounts.

## Install

```sh
bun add @voila.dev/ui-map
```

```css title="globals.css"
@import "@voila.dev/ui-map/styles.css";
```

## Import

```ts
import { MapView } from "@voila.dev/ui-map/components/map-view";
import { RadiusMap } from "@voila.dev/ui-map/components/radius-map";
```

Peers: `react@19`, `react-dom@19`, `tailwindcss@4`.
