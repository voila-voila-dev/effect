```tsx
<DropdownMenu>
	<DropdownMenuTrigger render={<Button variant="outline" />}>Actions</DropdownMenuTrigger>
	<DropdownMenuContent className="w-56">
		<DropdownMenuLabel>Match coverage</DropdownMenuLabel>
		<DropdownMenuGroup>
			<DropdownMenuItem>
				Edit mission
				<DropdownMenuShortcut>⌘E</DropdownMenuShortcut>
			</DropdownMenuItem>
		</DropdownMenuGroup>
		<DropdownMenuSeparator />
		<DropdownMenuItem variant="destructive">Cancel mission</DropdownMenuItem>
	</DropdownMenuContent>
</DropdownMenu>
```

`DropdownMenuLabel` has to sit inside a `DropdownMenuGroup` or at the top of the
content — a label floating between groups throws.

Checkbox and radio items are available as `DropdownMenuCheckboxItem` and
`DropdownMenuRadioItem` inside a `DropdownMenuRadioGroup`.
